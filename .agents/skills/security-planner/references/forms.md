# 表單匯入與回填

## 保存與對照

1. 原檔保留在專案指定來源目錄，記名稱、版本、hash、頁碼／工作表及填寫角色；輸出到新的檔名，禁止覆蓋原始表單。
2. 檢查合併儲存格、註腳、掃描文字與預勾選範例。保留問題原文及正式選項；示範的姓名、日期、勾選與「已完成」文字先辨識為範例，不當成已發生事實。
3. 為每個欄位建立 field→control_ids→column 的對照。不可自動按相似文字勾選。不能確定的欄位列待確認；每個必要欄位都要有映射或排除理由。
4. 計畫措施與實施情形分欄管理。內部狀態可為待規劃／待實作／待驗證；正式表若只有符合／不符合／不適用，未判定時保持未勾選並以註記或獨立待補清單說明。
5. 公司訓練、員工承諾、制度發布、設備盤點等需真實組織紀錄。機關意見、第三方結論與簽章由負責者提供，AI 不代填成已核定。

## 格式

- CSV：工具的 `fill-csv` 可依既定欄位映射，把已有證據的結果及說明寫入新副本；鍵值重複、欄位不存在、證據過期或輸出已存在時中止。輸出狀態為草稿，機關表的特殊選項先調整映射／人工核對。
- Word／ODT：使用實際可用的文件工具或文件 Skill，按表格、列、欄或內容控制項定位；保留條號、合併格、頁面及簽章區。輸出後重新開啟／渲染檢查，不宣稱通用工具能無損處理任何表單。
- Excel：使用實際可用的試算表工具或 Skill，按工作表與儲存格定位；保留公式、驗證規則、合併格與列印範圍，資料值不要當公式執行。
- PDF／掃描表：先確認可填欄位或可靠 OCR；有歧義時詢問或輸出欄位對照草稿。保留原始 PDF，不把 OCR 文本當作版面完整的正式交付。

無上述工具或實際表單時，先提供 Markdown／CSV 查核草稿與待補清單，不聲稱已完成 DOCX/XLSX/PDF 的原格式回填。

## 回填與複核

依實際結論生成符合／部分符合／不符合／不適用；尚無充分依據為待確認。每欄可追溯來源、控制項與證據。自訂正式選項不同時沿用原表格式，不擅自新增核定結論。
完成副本後檢查：欄位對應、原始問題未改動、必要欄位未遺漏、結論與總表一致、簽章未代填、實際排版可讀。只交付本機副本，對外提交另依既有授權。

CSV 工具只填已映射的欄位，其餘原文保留；這不表示整份正式表單填寫完畢。交付前逐列核對映射覆蓋，原表已預填的符合／簽名也須另外審查。回填結果含待確認者不能作為完成查核的正式結論。
