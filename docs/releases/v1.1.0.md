# MingMing v1.1.0 — AI 主導版

此版本回應核心目標：標準化 AI 開發流程與結果，AI 自主完成每個節點；只有查證後仍會影響結果的重要未知或授權缺口才詢問。

## 改變

- progress、模型能力評估不再要求例行人工確認；架構與資料設計在需求明確時可自主推進。
- 新增釐清政策、執行約定、Design Ready／Implementation Ready 與按風險選擇的適用階段。
- 統一 state.json；測試／review／文件以 Node、revision、attempt 與檔案 hash 留證據，修改來源後需重驗。
- 11 角色整合 API 契約、資料恢復、整合測試與文件義務；補齊 fast-track、completion、release 模板。
- 新增 AGENTS 與原生 skill 入口、Node.js 檢查器、證據記錄器、負向測試及 CI。
- 分開開發完成、發布成功、發布驗證與歸檔；補成效觀察方法與升級指引。

## 驗證與限制

自動測試涵蓋實際命令成敗、證據過期、錯誤版本、缺少 QA、阻塞問題、依賴循環與發布證據缺漏；亦檢查文件相對連結及入口。
可重現命令與結果見 [版本驗證報告](v1.1.0-validation.md)。本次是工作流工具維護驗證；真實產品試跑、跨模型成效與 LICENSE 仍未完成，已保留在追蹤表。
