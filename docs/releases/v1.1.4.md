# MingMing v1.1.4 — Draw.io 流程與架構圖整合

工作流版本及正式標籤為 **1.1.4／v1.1.4**，作為主線最新版本，保留所有舊版標籤及下載檔。

- 流程與架構角色按需使用 Draw.io；簡單說明仍可用文字／Mermaid，不要求每個任務畫圖。
- 共用圖表規範、操作指南及交接模板：來源／AC／決策對照、現況／規劃標記、人工修改讀回、增量更新、主檔及逐頁預覽、重新載入與目視檢查。
- 資安、資料、UIUX、QA、review、文件角色共用產物；圖表變更接回既有 evidence_files 與重驗規則。維持 12 角色，不新增 state 或 security-plan schema。
- 已選 Ming-design loop 時引用原設計交接；Draw.io 不自動啟用獨立 UIUX 流程。

## 升級與使用

由 v1.1.3 比較合併文件、角色入口及圖表交接模板；保留原專案客製規範與任務，無新增資料遷移。既有產品不自動升級。Draw.io MCP 是可選環境工具，不包含於下載包，不自動安裝或修改個人設定。

見 [導入指南](../adoption.md)、[圖表規範](../../ai-workflow/diagram-policy.md)與 [操作指南](../drawio.md)。下載包：MingMing-v1.1.4.zip。

## 驗證與限制

本機工具測試、隔離圖表操作與發布提交的雙平台 CI 分別記錄。隔離操作結果見 [圖表試驗](../../examples/diagrams/README.md)。工具操作試驗不等於真人手動修改、跨聊天協作或真實產品驗收；這些仍依試跑計畫完成。預覽渲染依賴瀏覽器，沒有新增圖表語意驗證器或背景同步；來源與圖面需實際 self-review。其餘限制見 [已知問題](../known-issues.md)。
