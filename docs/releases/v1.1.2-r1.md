# MingMing v1.1.2-r1 — 逐款資安規劃與代理執行修訂

工作流版本維持 **1.1.2**，發布標籤為 **v1.1.2-r1**，原 v1.1.2 標籤及下載檔保留。本次整合資安規劃師的逐款要求、完整表單對照、實際檢查執行與證據覆核。

- 將附表十拆為可獨立追蹤的要求：普 48、中 65、高 83 個內部細項；另列委外／年度稽核候選，逐案確認適用性。細項數不是官方原始表單列數。
- 每款連到措施、責任、開發節點、檢查步驟、通過條件與證據；一欄涵蓋多款時不得只完成其中一款就標符合。
- 保存真實命令結果、輸入版本、原始報告與產物指紋，逐項內容覆核；退出 0 不直接等於符合。資料變更會使舊證據失效。
- 記錄缺資料、外部責任與解除條件，保留原表並回填副本。附本機合成備份試辦：失敗、修正、重測、覆核與預期交付阻擋。

## 升級

schema v1 先 migrate 保留原檔並逐款重新覆核。舊 schema v2 使用 enable-execution 另存升級；保留證據但將舊符合結論回到待確認。新計畫預設啟用執行契約。既有產品不自動升級，同名檔案先比較再合併。

## 驗證與限制

99 項工具測試通過；Windows／Ubuntu CI 與套件校驗以本修訂的 GitHub Actions／Release 紀錄為準。合成試辦不代表實際政府案件驗收，沒有真實機關契約或正式表單；掃描器 adapter 與 Word／Excel／PDF 仍須依個案工具及原檔接入。執行器是證據紀錄工具，不是 OS sandbox；仍須遵守原有操作授權與平台權限。語意覆核為 self-review，不冒稱獨立檢測。
