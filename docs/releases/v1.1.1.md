# MingMing v1.1 — 主要版本（v1.1.1）

本版將 AI 主導工作流與精選 React 資源整合為 v1.1 系列的主要交付版本。完整套件包含 v1.1.0 的自治、角色、狀態與證據規範，以及後續的 React 選型更新。

## 包含內容

- AI 在已授權範圍自主完成 Node；重要資料缺口先查證，仍會影響結果才詢問。
- 11 個角色、Design Ready／Implementation Ready、唯一 state、版本與 hash 綁定證據、發布驗證。
- 四項精選資源：shadcn/ui（基礎介面）、ReUI（後台進階操作）、Magic UI（官網動效）、React Bits（特定視覺效果）。
- UIUX、前端、架構、QA、review、文件六個角色接入選型規則，既有元件優先、按需採用，不自動安裝全部或升級框架。

## 使用

下載本版完整 ZIP，依 [導入指引](../adoption.md)合併到專案，再讓 AI 讀取 AGENTS.md。資源使用規則見 [React 精選資源](../../ai-workflow/frontend-resource-map.md)。這個 repository 提供工作流與工具，本身沒有安裝 React 元件套件。

## 驗證

本地與 CI 執行 node scripts/check.mjs，包含文件連結與 34 個工具測試；另檢查 tasks/validation/release-v1.1.1/state.json 的有效證據。主線發布程序核對確切 commit、GitHub Latest、tag 與 ZIP 雜湊，實際遠端結果以 GitHub Release／Actions 為準。

Review 為 self-review。真實產品試跑、跨模型成本／成效量測與 LICENSE 仍待完成，見 [已知限制](../known-issues.md)。四項 UI 資源需在導入專案做實際整合與驗證。

## 版本定位

顯示名稱為「MingMing v1.1 — 主要版本」，精確版本／標籤為 v1.1.1。發布時設為 GitHub Latest；舊 v1.1 與 v1.1.0 tag 保留供追溯。VERSION、README 與下載套件使用同一版本。
