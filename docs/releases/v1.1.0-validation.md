# v1.1.0 驗證範圍

本版本以 Node.js 22 執行測試與文件／模板檢查。結果保存於 tasks/validation/workflow-v1.1.0 的實際維護任務證據，驗證命令如下：

```sh
node scripts/check.mjs
node scripts/validate-workflow.mjs --state tasks/validation/workflow-v1.1.0/state.json --require-active
```

validation 子任務狀態與證據是本次工作流維護的真實執行紀錄，並非可複製到新產品宣稱完成的範本。後續修改原始碼後，歷史 hash 可能失效；重驗歷史需回到對應版本 checkout。
CI 設定在 Windows 與 Ubuntu 執行檢查；本地成功與遠端 CI 結果分開核對，不能僅因已有 YAML 就聲稱兩個平台都通過。

review 模式為 self-review，涵蓋範圍：自治規則衝突、角色交接、狀態機、證據完整性、錯誤輸入與路徑處理。沒有產品 UI／API／DB 測試，也沒有跨模型實驗結果。
