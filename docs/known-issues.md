## v1.1.4 圖表整合

- 圖表規範是 agent 操作契約，沒有新的語意驗證器或跨聊天／Desktop 背景同步。
- MCP 及瀏覽器可用性依環境而異；PNG／SVG 或截圖失敗時記錄未完成，不以 XML 匯出成功代替。
- 本版只有隔離工具操作試驗；真人手動修改、跨聊天接續、真實產品的需求→圖→實作變更鏈仍待試跑。
- 公開版不含 Draw.io 安裝；套件授權、外部資源與敏感資料流需依實際版本及專案確認。
