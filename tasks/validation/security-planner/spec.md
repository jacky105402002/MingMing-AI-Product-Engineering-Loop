# 資安規劃擴充維護規格

使用者要求修改 MingMing 並整合資安規劃 Skill。本任務為工具維護，非政府採購專案；採 MingMing Full-Loop，風險 medium。GitHub 發布不在本次範圍。

## 驗收

- AC-1：高／中／普及未知可建立 62 項待確認草稿，來源可追溯，禁止無依據符合與默認普。
- AC-2：規劃／交付門檻連到 MingMing Nodes，保留舊狀態相容；證據與輸入異動能擋下過期結論。
- AC-3：表單原檔保存，CSV 按映射回填副本，複合控制全部核對；Word／Excel／PDF 規則如實記限制。
- AC-4：角色路由、文件、測試及本機入口同步；新擴充不冒稱已發布版。

## 設計與 Node

資料契約與 CLI 詳見 Skill 的 references。單一 node-security 主責完成來源、工具、測試與文件；腳本只用 Node 22 標準函式庫。UI 不適用，沒有網路 API。來源資料與控制項適用性須語意覆核，程式檢查不等於合規。

正式表單、實際標案契約與第三方報告目前未提供；使用合成測試資料驗證，不宣稱完成某個政府專案的驗收。
