# 逐款資安追蹤改善

使用者指出各級應有明確個別要求與繼承，否則查核表回填會出問題。沿用 MingMing Full-Loop，工具維護非政府標案，風險 medium。此輪完成本機改善，不改寫已發布 v1.1.2 標籤。

- AC-1：每款保留來源、條件及等級來源，高包含中、普並依原表共用格展開；未知不定級。
- AC-2：每款有措施、責任、Node、驗證及證據，刪款／變更條文／過期結論不能通過。
- AC-3：表單完整列盤點與全部相關細項對照；一欄缺任一必要細項不得符合。
- AC-4：schema v1 保留原檔後遷移，舊符合不自動分發，舊自訂要求／表單不能靜默遺失。
- AC-5：中文文件、案例示範、本機 Skill 與可用入口同步，發布狀態如實記錄。

單一 Node 完成資料、驗證器與指引，資料契約見 Skill references/data-contract.md。無 UI／網路 API。來源語意審查為 self-review；實際機關契約／表單未提供，示範只用合成資料。
