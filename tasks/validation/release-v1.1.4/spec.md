# MingMing v1.1.4 規格

沿用同一 MingMing 工作流維護任務；政府屬性 no，不另啟用 Ming-design loop。目標是加入 Draw.io 流程／架構圖操作及交付規範，延續已授權的主線版本發布與本機入口同步。

- AC-1：角色按需讀共用繪圖規範；包含來源、現況／規劃區分、必要詢問、完整圖檔、預覽、單一寫入者、交接與證據失效。不強制每個任務畫圖，不建立第二份業務規格。
- AC-2：獨立合成圖實測建立、讀回、增量修改、匯出、重新載入及目視檢查；保留不受修改節點。未做真人修改、跨聊天及真實產品驗收，不冒稱完成。
- AC-3：本機完整工具測試、文件及有效證據檢查；精確提交 CI Windows／Ubuntu 通過後發布 v1.1.4 ZIP／Latest，核對實際下載，再同步本機預設。保留舊版。

Allowed：state 中列出的文件、模板、隔離範例及新驗證證據。公開文件不含本機個人路徑、session 存取權杖或機密系統資料。禁止：修改產品程式／security schema、強制安裝 MCP、複製第三方套件進 ZIP、覆蓋既有圖或歷史 tag。沒有真人輸入時，不能偽造真人試跑。

本提交的發布狀態只到 ready；正式發布與下載回條另存工作區 outputs/release-v1.1.4，完成才記 verified。回復可選舊版固定標籤及本機備份，既有產品不自動升級。
