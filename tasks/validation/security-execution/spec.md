# 資安代理執行補強

沿用 MingMing Full-Loop；本工作為工具維護，非政府標案。保留前次未發布逐款改善與正式 v1.1.2；本輪不發布、不連線掃描正式環境。

AC-1：新計畫預設 execution_required；每款適用要求連到任務，指定實作位置、操作步驟、逐項通過條件、證據與責任。舊 v2 可明確 enable-execution，不靜默升級。
AC-2：在已授權環境執行明確 argv，限時與限輸出、保留真實回傳碼／原始 log／目標版本／輸入及產物指紋。回傳 0 不能取代逐項結果。程式不是 sandbox，命令仍須先讀碼與核對平台權限。
AC-3：逐項保存語意覆核觀察、理由、報告與關聯指紋；來源或版本更動不能沿用結論。外部責任與重要缺口有負責人、問題及解除證據，不能逾時自動解除。
AC-4：隔離的合成資料備份案例跑失敗、原因修正、重測、內容覆核、表單草稿；缺機關資料仍阻擋整案交付，不冒稱實際標案驗收。
AC-5：Skill、操作指南、測試與本機入口同步，留存還原與限制。單一 agent 自我審查，不宣稱獨立檢測。

無 UI、網路 API 或套件新增。本輪保留現有法規目錄，不新增或變更法律適用判斷。所有真實案件仍需重新核對其官方版本與契約。
